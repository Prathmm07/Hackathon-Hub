# Hackathon Hub 🚀

A centralized web application designed for students and organizers to discover hackathons, manage collaborative team registrations, and submit project entries seamlessly.

Built using **Python**, **Flask**, and **PostgreSQL**.

---

## 📌 Key Features

- **Hackathon Discovery:** Browse upcoming hackathons, event timelines, guidelines, and competition categories.
- **User Authentication & Profiles:** Secure session-based authentication for participants and organizers.
- **Team Management:** Form, join, and manage teams with collaborative member invitations.
- **Project Submissions:** Submit project links, abstracts, and documentation for evaluation.
- **Relational Data Management:** Normalized PostgreSQL database tables ensuring zero data redundancy and secure transactions.

---

## 🛠️ Tech Stack

- **Backend:** Python, Flask
- **Database:** PostgreSQL / SQLite
- **Frontend:** HTML5, CSS3, JavaScript
- **Security:** Parameterized queries, Session Authentication

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/prathmeshmaid/Hackathon-Hub.git
cd Hackathon-Hub
```

### 2. Set up a Virtual Environment
```bash
python -m venv venv
# On Windows:
venv\Scripts\activate
```

### 3. Install Dependencies
```bash
pip install flask psycopg2-binary
```

### 4. Run the Application
```bash
python app.py
```
Open your browser and navigate to `http://127.0.0.1:5000`.
